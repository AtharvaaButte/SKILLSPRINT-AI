# 🚀 SkillSprint AI

**SkillSprint AI** is an AI-powered placement preparation platform that generates  
**personalized, time-based learning roadmaps** based on a student’s current skills,  
target job role, and available preparation time.

Instead of generic advice, SkillSprint AI helps students focus only on what truly matters  
for their desired role — week by week.

---

## 🧠 Problem Statement

Students preparing for placements often:
- Don’t know **what to study first**
- Follow **unstructured and generic roadmaps**
- Waste time on topics not aligned with their target job role

There is a lack of **personalized, role-specific, and time-aware preparation guidance**.

---

## 💡 Solution Overview

SkillSprint AI analyzes:
- User’s current skills and proficiency levels  
- Target job role (Frontend, Backend, Full Stack, etc.)  
- Available preparation time and learning preferences  

Using AI, it generates a **structured roadmap** divided into months and weeks, where each week includes:
- Focused topics  
- Learning resources  
- A mini assignment  
- Progress tracking  

The platform acts as a **virtual AI career coach**, guiding users step-by-step toward placement readiness.

---

## ✨ Key Features

- **Personalized Roadmap Generation**  
  AI-generated, role-specific preparation plans.

- **Skill Gap Analysis**  
  Identifies strengths, skills needing revision, and missing skills.

- **Weekly Task Breakdown**  
  Topics organized week-wise with learning resources.

- **Progress Tracking**  
  Checkbox-based tracking for topics, weeks, and months.

- **Preference-Aware Assignments**  
  Roadmaps adapt based on user preferences (e.g., project-based learning).

- **Google Authentication (UI)**  
  Simple Google sign-in flow for user access.

- **Gemini-Inspired Dashboard UI**  
  Clean, minimalist interface with sidebar navigation and timeline view.
